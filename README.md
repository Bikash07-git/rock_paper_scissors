## 🚀 ENTER THE BATTLE ZONE

Ready to play? Follow these steps to launch the game on your machine.

### 📋 Prerequisites

- Python 3.13.2 or a compatible Python 3 version
- Git installed on your system

### ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/Bikash07-git/rock_paper_scissors.git
```

**2. Enter the Battle Zone**

```bash
cd rock_paper_scissors
```

**3. Launch the game**

```bash
python game.py
```

🎮 **That's it! The game is ready. Let the battle begin!**

## 📦 BUILD YOUR OWN EXECUTABLE

Want to take the battle offline?

Package the game into a standalone Windows executable using PyInstaller.

**Install PyInstaller**

```bash
pip install pyinstaller
```

**Build the executable**

```bash
pyinstaller --onefile --windowed game.py
```

Your executable will be generated inside the `dist` directory.

⚡ **No terminal. No setup. Just launch and play!**
